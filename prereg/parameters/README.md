# Parameter Studies

A **parameter** changes what the engine finds. A [filter](../filters/) discards from what it already
found. Parameter studies generate a different trade set; filter studies thin an existing one.

The 0-for-8 filter record does not apply to a parameter question, and saying so is not special
pleading — it is the reason the distinction is maintained. It is also the test for whether a new
proposal has quietly become a filter while being described as something else.
